# 가상현실 중간 프로젝트

**현재 구현: v5 독립 상품 인식 (2026-10-26).** 앞면 이미지와 바코드는 서로를 기다리지 않고 정보를 표시한다. 앞면은 3D, 바코드는 2D 정보판이며 같은 상품은 3D를 우선한다. 목표·등록 상태 4종·데이터 모델은 [v5 상품 인식 구조](docs/PRODUCT-RECOGNITION-V5.md)를 따른다.

테아닌 밀크씨슬 박스는 사용자 제공 바코드 `8809375984692`·약 58mm 폭과 `iphone-t1`의 상단 95점·하단 100점 크롭을 등록했다. 원격 PriceTrace ID는 확인하지 못해 **로컬 시연 UUID**로 구분했고 가격·영양값은 비워 뒀다. 브이젤 카드와 더단백의 개발용 연결은 계속 구분 표시한다.

**EditMode 105/105 PASS**, 실패·건너뜀 0。사용자가 초기 v5의 앞면·바코드 정상 동작을 보고했고 갤러리의 3D 출력 화면을 확인했다. 앞면 정보판을 60%로 줄이고 소실 후 새 상품 인식으로 자동 복귀하도록 수정해 Galaxy A25에 `0.5.1 (6)`을 호환 업데이트했다. 카메라·SessionTracking·대기 화면과 설치 APK 해시는 확인했으며, 업데이트 후 실물 재시험은 남아 있다. [검증 기록](docs/VALIDATION.md), [최신 검증 요약](docs/validation/v5-rescan-panel-fix-2026-10-26.json). 이전 바코드 선행 흐름은 [v4 구현](docs/PRODUCT-IMAGE-TRACKING.md)에 보존한다.

상품마다 추가 마커를 붙이지 않는 확장은 [바코드 마커 기술 조사 보고서](docs/BARCODE-MARKER-RESEARCH.md)에 정리했다. ZXing·OpenCV 등 공개 구현, 2D 검출과 3D 자세 추정의 차이, 과제 적합성과 후속 검증 범위를 비교한다.

외부 API로 상품명을 찾고 PT 등록·연결 상태를 표시하는 방안은 [바코드 상품 검색·PT 연결 도입 보고서](docs/BARCODE-PRODUCT-LOOKUP-RESEARCH.md)를 따른다. Open Food Facts·식품안전나라·네이버 쇼핑의 역할과 한계, PT 식별자 모델, 늦은 응답·조회 실패 처리를 제안한다. 외부 검색과 PT 실시간 연결은 아직 구현하지 않았다.

바코드로 상품을 식별하고 사전 등록 이미지로 3D 위치를 추적하는 Android AR 카메라 앱이다.

강의 원문과 방향 선택 근거는 [강의 검토·완성 계획](docs/COURSE-ALIGNED-PLAN.md)에 정리했다. 현재 진행 상태는 [마일스톤](docs/MILESTONES.md), 이번 변경 묶음은 [작업 기록](docs/WORKLOG.md)을 따른다. 이전 v3의 2D 바코드 추종은 [기존 흐름](docs/BARCODE-FOLLOW.md), v2의 평면 배치는 [기존 마일스톤](docs/MILESTONES-V2.md)에 보관한다.

## 사용 흐름

- **앞면 경로:** 등록 이미지를 비추면 곧바로 상품의 3D 정보판을 표시하고 영양/가격 탭을 전환한다. 바코드가 없는 상품도 지원한다.
- **바코드 경로:** EAN-13을 3회 확인하면 독립적인 2D 정보판과 앞면 등록 여부 배지를 표시한다. 이미지가 없어도 사용할 수 있다.
- 같은 상품의 복수 앞면은 허용한다. 다른 상품의 앞면이 동시에 보이거나 서로 다른 앞면/확정 바코드가 충돌하면 숨긴다.
- 미등록 번호는 읽은 번호와 **로컬 카탈로그 스냅샷 날짜**를 표시한다. 운영 PriceTrace 전체의 미등록을 단정하지 않는다.
- 소실·제한·LAST_KNOWN_POSE·pause에서는 잘못된 공간 표시를 숨긴다. 재획득·같은 상품 크롭 전환은 탭을 유지하고 다른 상품·재스캔은 초기화한다.

## 이전 구현·기기 검증 기록

다음 항목은 v3·v2 당시의 성과다. 현재 이미지 정보판의 코드 검증과 실물 성공을 구분한다. 전체 이력은 [구현·검증 기록](docs/VALIDATION.md)을 따른다.

- 바코드 판독, 정확한 로컬 매핑, 한국어 정보창, 자동 표시·선택 번호 추종·소실 시 숨김·다른 상품 스캔을 구현했다.
- Unity EditMode 자동 시험 **42/42 통과**. 회전 입력의 위치 좌표·화면 변환·잘림·오래된 결과·다른 상품 거부·추종 중지와 재시작, 영양성분표·가격의 값·단위·누락값을 포함한다. 기존 기기 시험은 이전 평면 배치 빌드의 기록이다.
- 카메라 UI를 스캔·추종 2단계로 구성했다. 상품 확인 후 재배치·삭제 없이 자동 표시하며, 위치 준비·소실·권한 오류를 구분한다.
- 영양정보를 기준량·열량과 성분별 함량이 정렬된 표로 표시한다. 관측 가격은 금액을 강조하고 판매처·관측일·개당 기준을 분리한다. 누락값과 0을 구분한다.
- Galaxy A25 / Android 16에 설치·실행하고 카메라 영상, 실제 1920×1080 CPU 이미지 입력, 합성 EAN-13의 Android 디코더 자체 점검을 확인했다.
- 2026-10-24 센서 요청 보완 후 실제 수평 평면 감지·터치 앵커 생성·정보판 배치를 로그와 사용자 화면으로 확인했고, 사용자가 휴대폰 이동 중 같은 책상 위치에 유지됨을 확인했다. AR 사용 중 100Hz 센서 요청을 유지하고 pause/복귀 시 해제·재등록한다. **10회 반복·장시간 검증은 미완료**다.
- 단발성 판독으로 미등록 안내가 확정되던 문제를 수정했다. 같은 번호를 3회 연속 확인하고, 미등록 시 읽은 번호를 표시한다. 반복 오독 재현 후 판독 영상을 640×480에서 1920×1080으로 높였다. 실제 입력은 [해상도 분석 기록](docs/BARCODE-RESOLUTION.md)을 따른다. 2026-10-24 사용자가 수정 앱의 실물 스캔 후 정확한 상품명 표시를 확인했다. 10회 반복 시험과 현실 공간 배치는 별도 검증한다.
- 바코드 연결은 사용자 제공 근거의 **demo-only** 매핑이다. 운영 DB의 기존 매핑은 미검증이다.
- 이미지 품질은 새 M0의 통과 조건이 아니다. 과거 시험은 [구기획 검증 기록](docs/M0-M3-validation.md)에 보존한다.

## 개발 환경

- Unity **6000.3.22f1 LTS**, AR Mobile Template **2.1.2** 기반.
- AR Foundation / ARCore XR Plugin **6.3.5**. 실제 패키지 버전은 `Packages/manifest.json`과 `Packages/packages-lock.json` 참조.
- ZXing.Net **0.16.11**, Unity Newtonsoft JSON **3.2.2**, OFL Noto Sans CJK KR을 사용한다. 바코드는 동일 AR 카메라의 CPU 이미지에서 판독한다.
- Unity Hub에 이 폴더를 추가하고 지정 에디터 버전으로 연다.
- 실행 씬은 **`Assets/Scenes/ProductAR.unity`**다. `SampleScene.unity`는 보존한 템플릿 샘플이다.
- `lecture/`는 강의 원본이다. 생성 캐시·로그·APK·키·로컬 조회 원문은 Git에서 제외한다.

## 빌드·설치·남은 검증

2026-10-26 v5 `0.5.0 (5)` 새 설치 후 `0.5.1 (6)`로 호환 업데이트했다. 기능 검증은 `scripts/Test-EditMode.ps1`, 씬·프리팹 갱신은 Unity 메뉴 **Product AR → Prepare Image Tracking Scene (No Build)**를 사용한다.

- APK: `Builds/Android/ProductAR.apk` (생성 파일, Git 제외), 앱 이름 **상품정보 AR**, 패키지 `com.yeonsik.midtermar`.
- 재빌드: `scripts/Build-Android.ps1`. 한글 경로 제한을 피하도록 영문 임시 복사본에서 빌드한다.
- 설치·실행: `scripts/Install-Android.ps1 -DeviceSerial <serial> -Launch`. 서명·버전을 확인한 `-r` 업데이트를 사용한다.
- 씬·프리팹 재생성: Unity 메뉴 **Product AR → Prepare Project and Scene**. 생성 씬을 수동 수정했다면 재생성 전 내용을 보존한다.
- 남은 실물 시험: [현재 이미지 정보판 체크리스트](docs/DEVICE-CHECKLIST.md). 포장 앞면 추적·회전·거리 변화·소실·재획득과 탭 터치를 확인해야 한다. 평면 배치는 [v2 체크리스트](docs/DEVICE-CHECKLIST-V2.md)에 보관한다.
- 제출 준비: [중간보고서 초안](docs/REPORT-DRAFT.md) (v4 이미지 추적 기준, 2026-10-25). 배경 통계·공식 사례, 강의 적용·현재 구현·검증 수준·AI 활용을 반영했다. 실제 상품 기기 시험, 학번·이름·템플릿 Word·데모 영상은 남아 있다. 마감은 사용자 제공 **10월 29일**, 시각은 미확인이다.
