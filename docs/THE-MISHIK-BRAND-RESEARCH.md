## 데이터에 적용할 판단

- **브랜드 별도 등록:** 적절하다. 법인과 브랜드는 다른 대상이므로 상품 브랜드를 운영사명으로 일괄 치환하지 않는다.
- **브랜드 공식 사이트:** 기존 초안의 기업 사이트 `harimglobal.com`에서 브랜드몰 `the-mishik.com`으로 정정한다.
- **운영 주체:** 주식회사 하림산업으로 조사 메타데이터에 기록한다. 법적 상표권 등록 명의까지 조회한 결과는 아니다.
- **상위 브랜드 ID:** 최초 초안의 `parentBrandId=null` 유지 판단은 대체했다. PT 확정 계약에서 null은 root이며, 부모 관계는 관리자 명시 연결이다. 사용자 계층 관리 지시에 따라 하림 ID `e0868ff8-1630-4b43-81eb-7e7177fdf855`를 The미식 ID `b3d52f8c-5cb0-4eda-bf94-d0c52d116289`의 부모로 등록했다. 하림은 기존 검색에 없어 새로 생성했으며 익명 공개 브랜드 API가 부모명 하림을 반환함을 확인했다. 상품의 `brand_id`는 가장 구체적인 The미식을 참조한다.

위 판단은 신규 브랜드 데이터의 분류·출처에 관한 것이다. 상품의 단품 EAN `8809778493005`, 121g·1봉 규격, 영양값은 사용자 포장 사진을 근거로 유지한다. 공식몰의 묶음 가격을 구매 관측가로 사용하지 않는다.

## 반영과 검증 경계

[B 적용안](B-THREE-PRODUCTS-PLAN.md)과 [등록 데이터](data/b-three-products-2026-10-28.json)에 공식 URL·운영사·대체 표기·근거 링크와 실제 계층 ID를 반영했다. 운영사 메타데이터와 대체 표기는 검토 JSON에만 보존하며 운영사 테이블이나 별칭 테이블은 생성하지 않았다. 하림·The미식 2개 브랜드, 상품·EAN·공개 영양 각 3개를 추가했고 [적용 기록](validation/b-three-products-applied-2026-10-28.json)에 익명 HTTP 확인과 기기 미수행을 구분했다.
