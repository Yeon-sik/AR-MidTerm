# 이미지 추적 상품정보판 — 실물 검증 절차

2026-10-27 최신화. **아래 항목은 시험 절차이며 실제 수행 결과는 VALIDATION.md와 검증 JSON에 따로 기록한다.** 온라인 조회 추가 EditMode 162/162를 확인했다. 자동 시험을 실물 성공으로 대체하지 않는다.

현재 규칙은 [v5 독립 인식](PRODUCT-RECOGNITION-V5.md)과 [온라인 조회](ONLINE-LOOKUP.md), 결과 기록은 [VALIDATION.md](VALIDATION.md)를 따른다. 이전 평면 배치는 [v2 체크리스트](DEVICE-CHECKLIST-V2.md)에 보관한다.

## 준비 조건

- 실제 상품: 더단백 크런치바 초코 40g, EAN-13 **8801104671507**. 가격·영양은 로컬 시연 데이터다.
- 실제 포장을 시험하려면 원본/보정 사진, 선택 영역의 실측 너비·높이, 이미지 이름, 라이브러리와 JSON 연결을 기록한다. 상품 마커는 developmentOnly=false와 Physical Size를 확인한다.
- 현재 test-card를 사용하면 **개발용 카드 연결 시험**으로 기록한다. 더단백 바코드를 선택한 뒤 카드를 비추는 결과를 상품 포장 인식 성공으로 기록하지 않는다.
- 추후 새 통합 APK가 준비되면 소스 커밋·SHA-256·패키지·버전과 실행 씬 ProductAR를 확인한다. ImageTrackingProbe의 큐브 APK와 구분한다.
- 기기·OS·조명·거리·각도를 기록하고 명시적인 대상 기기에서 설치·실행한다. 서명 불일치를 정상 업데이트로 기록하지 않는다. 실행 캐시 files/il2cpp는 데이터 복원 대상에서 제외한다.

## 반복·부하 기록

각 시도마다 상품을 화면 밖으로 뺐다가 다시 보여주고 바코드 판독과 이미지 표시의 시간을 분리해 측정한다.

| 시도 | 조건·마커 모드 | 실제 번호/형식·판독 시간 | 이미지 표시 시간 | 위치·방향·탭·소실·재획득 | 실패/복구·근거 |
|---|---|---|---|---|---|
| 1~10 | 조명·거리·각도, 카드/실제 포장 | 실제 결과 | 실제 결과 | 실제 결과 | 영상/로그 |

개발 목표는 동일 조건에서 10회 중 8회 이상 5초 내 식별/표시, 잘못된 상품 표시 0회다. 공식 채점 기준이나 이미 달성한 성과가 아니다. 5분 연속 사용과 반복 재스캔에서 크래시·리소스 누적·발열을 관찰하고 측정 도구·조건을 기록한다.

기존 센서 보완을 확인할 때는 AR 사용 중 등록·pause 해제·복귀 재등록 로그를 남긴다. 등록 성공만으로 정확한 센서 주기나 앱 성능 향상을 주장하지 않는다.
