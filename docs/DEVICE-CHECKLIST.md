# 이미지 추적 상품정보판 — 실물 검증 절차

2026-10-25 최신화. **아래 절차는 계획이며 이번 작업에서는 미실행이다.** 현재 통합은 EditMode 76/76까지 확인했고 새 앱 빌드·APK 생성·설치는 하지 않았다. 기존 APK는 이번 정보판 기능을 포함한 결과가 아니다.

구현 규칙은 [PRODUCT-IMAGE-TRACKING.md](PRODUCT-IMAGE-TRACKING.md), 결과 기록은 [VALIDATION.md](VALIDATION.md), 이전 평면 배치는 [DEVICE-CHECKLIST-V2.md](DEVICE-CHECKLIST-V2.md)를 따른다.

## 준비 조건

- 실제 상품: 더단백 크런치바 초코 40g, EAN-13 **8801104671507**. 가격·영양은 로컬 시연 데이터다.
- 실제 포장을 시험하려면 원본/보정 사진, 선택 영역의 실측 너비·높이, 이미지 이름, 라이브러리와 JSON 연결을 기록한다. 상품 마커는 developmentOnly=false와 Physical Size를 확인한다.
- 현재 test-card를 사용하면 **개발용 카드 연결 시험**으로 기록한다. 더단백 바코드를 선택한 뒤 카드를 비추는 결과를 상품 포장 인식 성공으로 기록하지 않는다.
- 추후 새 통합 APK가 준비되면 소스 커밋·SHA-256·패키지·버전과 실행 씬 ProductAR를 확인한다. ImageTrackingProbe의 큐브 APK와 구분한다.
- 기기·OS·조명·거리·각도를 기록하고 명시적인 대상 기기에서 설치·실행한다. 서명 불일치를 정상 업데이트로 기록하지 않는다. 실행 캐시 files/il2cpp는 데이터 복원 대상에서 제외한다.

## 기능별 기대 결과

| 시험 | 행동 | 기대 결과 |
|---|---|---|
| 상품 선택 | 바코드 전체와 흰 여백을 선명하게 비추기 | 서로 다른 프레임의 3회 일치 후 정확한 상품명·규격 |
| 앞면 전환 | 바코드에서 등록 이미지로 돌리기 | 선택 유지, 일치 이미지 FULL_TRACKING 후 정보판 |
| 3D 정합 | 휴대폰 각도·거리, 이미지 위치·방향 변경 | 같은 이미지의 위치·방향을 따름. 화면 중앙·책상 잔상과 구분 |
| 영양 탭 | 영양 버튼 누르기 | 40g 기준량·단위·출처 표시, 가격 페이지 숨김 |
| 가격 탭 | 가격 버튼 누르기 | 1,400원, 판매처, 2026-05-08 관측일·출처. 현재가로 표현하지 않음 |
| 이미지 소실 | 등록 이미지를 완전히 가리거나 화면 밖으로 빼기 | 마지막 위치에 남지 않고 숨김 |
| 재획득 | 일치 이미지를 다시 비추기 | 같은 선택·탭으로 복구 |
| 다른 번호 | 다른 유효한 EAN을 비추기 | 기존 정보판 숨김, 자동 상품 전환 없음. 원래 번호로 돌아와도 재스캔 필요 |
| 다른 이미지 | 다른 등록 이미지만 또는 두 등록 이미지를 함께 비추기 | 기존 정보판 숨김, 일치 이미지만 다시 보이면 복구. 현재 라이브러리 1종이면 이 조건은 미준비로 기록 |
| Home 복귀 | Home 후 앱으로 돌아오기 | 새 프레임·이미지 갱신 전 이전 자세를 표시하지 않음 |
| 재스캔 | 정보판 또는 안내의 다른 상품 스캔 누르기 | 상품·자세·본문 초기화, 새 상품 바인딩에서 영양 탭 |
| 미등록 번호 | 재스캔 후 카탈로그에 없는 유효한 EAN 비추기 | 읽은 번호와 미등록 안내, 더단백으로 임의 연결하지 않음 |
| 권한·세션 | 권한 거부/허용, 밝기·과도한 움직임에 따른 상태 관찰 | 준비/복구 안내, 추적 불가 중 잘못된 자세의 정보판 없음 |

가격·영양 누락값/0의 코드 시험은 이미 수행했다. 실기기 재현을 위해 운영 데이터나 실제 시연값을 임의로 바꾸지 않는다. 별도 시험 데이터를 사용하면 원본과 구분해 기록한다.

## 반복·부하 기록

각 시도마다 상품을 화면 밖으로 뺐다가 다시 보여주고 바코드 판독과 이미지 표시의 시간을 분리해 측정한다.

| 시도 | 조건·마커 모드 | 실제 번호/형식·판독 시간 | 이미지 표시 시간 | 위치·방향·탭·소실·재획득 | 실패/복구·근거 |
|---|---|---|---|---|---|
| 1~10 | 조명·거리·각도, 카드/실제 포장 | 실제 결과 | 실제 결과 | 실제 결과 | 영상/로그 |

개발 목표는 동일 조건에서 10회 중 8회 이상 5초 내 식별/표시, 잘못된 상품 표시 0회다. 공식 채점 기준이나 이미 달성한 성과가 아니다. 5분 연속 사용과 반복 재스캔에서 크래시·리소스 누적·발열을 관찰하고 측정 도구·조건을 기록한다.

기존 센서 보완을 확인할 때는 AR 사용 중 등록·pause 해제·복귀 재등록 로그를 남긴다. 등록 성공만으로 정확한 센서 주기나 앱 성능 향상을 주장하지 않는다.

## 결과와 제출

실행 날짜·커밋·기기·APK 해시·절차·기대/실제 결과·PASS/FAIL/NOT RUN·원시 근거를 VALIDATION.md에 추가한다. 자동 시험, 카드 큐브, 실제 포장 정보판의 결과를 섞지 않는다. 검증된 흐름만 1~2분 무음성 시연 영상에 사용한다. 마감은 사용자 제공 10월 29일이며 시각·파일명·업로드 조건은 이클래스 공지와 대조한다.
