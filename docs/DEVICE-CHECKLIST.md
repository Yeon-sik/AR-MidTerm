| 테아닌 영양 탭 | 테아닌 앞면 정보판의 영양 버튼 누르기 | 가격으로 시작하고 영양 탭은 흐리게 비활성. 터치해도 빈 영양 화면으로 바뀌지 않음 |

가격·영양 누락값/0의 코드 시험은 이미 수행했다. 실기기 재현을 위해 운영 데이터나 실제 시연값을 임의로 바꾸지 않는다. 별도 시험 데이터를 사용하면 원본과 구분해 기록한다.

## 반복·부하 기록

아래 **최소 5회는 사용자가 수행할 테아닌 앞면 시험 양식**이다. 결과 칸은 비워 두며 미수행을 PASS로 채우지 않는다. 바코드를 먼저 읽지 않은 상태에서 시작해 앞면 AR을 독립적으로 확인한다.

시도마다 정면에서 첫 3D 표시 → 좌우 회전 → 거리 변경 → 완전 가림 → 재노출을 수행한다. 예시 범위는 회전 15~30도·거리 20/30/40cm이며 실제 조건과 실측/추정 여부를 기록한다. 상단·하단 크롭 전환과 탭 유지도 확인한다. 가능하면 영상 시각으로 첫 표시와 재획득 시간을 잰다.

|---|---|---|---|---|---|---|
| 1 | | | | | | |

실제 수행 횟수와 성공·실패·재획득 횟수를 함께 적는다. 5초 내 표시·잘못된 상품 표시 0회는 개발 확인 목표이며 공식 채점 기준이나 이미 달성한 성과가 아니다. 반복과 별도로 5분 연속 사용 시 크래시·리소스 누적·발열을 기록할 수 있다. 바코드 반복 시험과 개발용 카드 시험은 별도 표에 기록한다.

기존 센서 보완을 확인할 때는 AR 사용 중 등록·pause 해제·복귀 재등록 로그를 남긴다. 등록 성공만으로 정확한 센서 주기나 앱 성능 향상을 주장하지 않는다.

## 결과와 제출

실행 날짜·커밋·기기·APK 해시·절차·기대/실제 결과·PASS/FAIL/NOT RUN·원시 근거를 VALIDATION.md에 추가한다. 자동 시험, 카드 큐브, 실제 포장 정보판의 결과를 섞지 않는다. 검증된 흐름만 1~2분 무음성 시연 영상에 사용한다. 마감은 사용자 제공 10월 29일이며 시각·파일명·업로드 조건은 이클래스 공지와 대조한다.
