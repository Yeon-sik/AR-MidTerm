## 2026-10-25 이미지 추적 정보판 통합과 보고서 최신화

### 요청과 범위

강의에서 배운 이미지 추적·World Space UI·버튼 상호작용 범위에서 상품정보판과 영양/가격 전환을 구현했다. 앱 빌드·APK 생성·설치·실물 시험은 제외하고 코드 기능을 검증했다. 이후 보고서와 작업 문서를 현재 구현에 맞춰 최신화하고 기능 브랜치에 기록하는 작업이다.

### 구현

- 바코드 상품 선택과 이미지의 3D 자세를 연결했다. 앞면 전환 중 바코드가 사라져도 선택을 유지한다.
- FULL_TRACKING에서만 표시하고, 이미지 소실·제한·다른 이미지·pause에서 숨긴다. 다른 EAN은 자동 전환 없이 재스캔을 요구한다.
- World Space 정보판에 영양/가격 탭·재스캔과 출처·관측일·기준량·누락값/0 처리를 연결했다.
- 상품↔이미지 JSON과 별도 ProductImageLibrary를 추가했다. 상품 포장에는 Physical Size를 요구하고, 현재 카드 연결은 개발용임을 화면에 표시한다.
- 기존 카드의 추적 정책을 공유하며 기본 모드의 평면·Raycast·앵커와 2D 표시기를 비활성화했다.
- 씬·프리팹 갱신과 EditMode 검증 경로를 앱 빌드 명령에서 구분했다.

### 검증

- 최종 EditMode **76/76 PASS**: 기존 51개, 새 이미지 정보판 25개. 실패·건너뜀 0, Unity exit 0.
- 실제 앱의 바코드 선택→정보판→재스캔, 3D 계산·pause, 설정 검증·다른 대상 거부, 탭·포인터 영역·이벤트와 데이터 재바인딩을 검사했다.
- 네이티브 화면 렌더링의 히트 정렬·휴대폰 터치·실제 포장 정합은 시험 범위 밖이다.
- Android 설정과 기존 probe 씬·라이브러리를 보존했다. 기존 APK의 목록·크기·해시·수정 시각이 일치한다.
- 근거: [검증 기록](VALIDATION.md), [공개 시험 요약·소스 해시](validation/product-image-panel-2026-10-25.json). 원시 로그·입력 보존본은 Git 제외 artifacts/editmode/에 둔다.

### 문서 최신화

- 중간보고서를 v4 이미지 추적 방식으로 재작성했다. 강의 적용, AR 활용 목적, 76개 코드 시험, 과거 기기 성과, 미검증 항목과 AI 활용을 반영했다.
