# 테아닌 포장 주석 앵커 측정

지시선은 2mm 두께를 재사용하되 끝 캡을 평평하게 해 앵커를 지나 인쇄 안쪽으로 뻗지 않도록 한다. 규격 줄의 앵커는 글자 왼쪽 6px 밖이며, 상자 앵커는 윗변 위에 있다.

계산용 용량 60g(테아닌)·40g(더단백)은 요청서가 지정한 PT 공개 카탈로그 content_amount 근거를 구조 필드로 옮겼다. 60정은 원본 규격 줄의 포장 표기 근거와 함께 저장했다. 규격 문자열에서 숫자를 추출하지 않으며, PT 응답의 용량 쌍은 전달하되 정 수를 만들지 않는다.

2026-10-28. 이 기록은 사진상의 위치 측정이며 실물 정합 성공 기록이 아니다. 1번 정보판은 상품 단위 정보이고, 2번은 특정 인쇄 위치를 가리키는 계산 주석이다. 실물 사용자 확인 전 제출 기준은 변경하지 않는다.

원본 `iphone-t1.jpg`는 **1208×2425px**, SHA-256 `77b87ec91116535aff963106b6dfc904207d1663bf4cde3dc37ffeb721d75229`다. 크기 변경·추가 원근 보정 없이 원본 픽셀을 사용했다. 위·아래 크롭의 기존 공통 원점은 `(604, 1212.5)`이며 **+X는 오른쪽, +Z는 아래쪽**이다. 사용자가 제공한 폭 약 58mm를 사용해 축척을 `0.058 / 1208 = 0.000048013245m/px`로 계산했다. 높이는 `2425 × 축척 = 0.116432m`에서 **0.1164m**로 기록한다. 높이는 사진 기반 환산이며 실측값이 아니다. 기존 크롭 오프셋은 변경하지 않는다.

| 주석 | 다시 측정한 대상 경계 (오른쪽·아래 제외) | 앵커 픽셀 | 공통 좌표 X / Z (m) |
|---|---|---|---|
| 정 수 가격 | 규격 줄 `[43,2129]~[728,2210)` | `(37,2169.5)` | `-0.027223510 / +0.045948675` |
| 관측 판매처 | 군마트용 상자 `[880,62]~[1154,153)` | `(1017,63.5)` | `+0.019829470 / -0.055167219` |

측정은 원본을 시각적으로 확인해 대상별 ROI를 정한 뒤 어두운 인쇄 픽셀의 경계를 계산했다. 규격 줄 ROI는 x20~799/y2128~2214, 평균 RGB<175다. 위의 다른 문구와 아래 문구를 분리해 규격 줄만 잡았다. 앵커는 검출 왼쪽 끝에서 6px 왼쪽, 줄 높이의 중앙이다. 상자 ROI는 x860~1179/y40~179, R<125·G<100·B<100이다. 앵커 X는 상자 경계의 중앙이며, Y는 중앙 부근 x1009~1025에서 검출된 상단 검은 경계의 중앙값 63.5px다. 전체 bbox의 최상단과 기울어진 상자 중앙의 실제 윗변을 구분했다.

변환은 `X=(pixelX-604)×축척`, `Z=(pixelY-1212.5)×축척`이다. 재현 명령은 `python scripts/Measure-AnnotationAnchors.py iphone-t1.jpg`이며 Pillow를 사용하고 원본을 수정하지 않는다. 사진의 흐림·경계 임계값과 포장 원근 오차가 있으므로 이 좌표는 실물 측정을 대신하지 않는다. 사용자 실물에서 방향·거리 오차를 확인하고 필요하면 좌표만 한 번 조정한다.

라벨은 상품 왼쪽·위쪽 경계에서 12mm 밖에 놓는다. 글자 em 높이는 5mm이며 라벨은 이미지 평면과 평행하다. 위 라벨의 오른쪽 끝은 1번 정보판 왼쪽보다 2mm 상품 쪽으로 제한한다. 지시선은 인쇄 앵커와 라벨 가장자리 사이, 평면 위 1mm에 그린다. 원본의 인쇄 문구는 주석 내용의 법적 판단 근거로 사용하지 않는다.
