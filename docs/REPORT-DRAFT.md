# 바코드 기반 상품정보 AR — 중간보고서 초안

작성일: 2026-10-23. 학번·이름: **제출자가 입력**. 이 문서는 제출 초안이며 실제 구현·검증 범위는 [VALIDATION.md](VALIDATION.md)와 대조한 뒤 제출한다.

## 1. 콘텐츠 기획의도

### 배경과 필요성

실물 상품의 가격·영양정보를 확인하려면 상품명과 용량을 파악해 검색하고 정확한 상품을 다시 선택해야 한다. 이 프로젝트는 제품의 바코드를 입력으로 사용해 그 선택 과정을 줄이고, 확인한 정보를 사용자가 지정한 상품 옆 현실 공간에 배치하는 모바일 AR 인터페이스를 구현한다.

첫 시연 상품은 빙그레 더단백 크런치바 초코 40g이다. 기존 PriceTrace의 정확한 규격과 Nutrition 연결 근거를 조사했고, 로컬 스냅샷을 사용한다. 가격은 2026-05-08의 개당 1,400원 관측이며 현재가·가격 추이로 표현하지 않는다. 바코드 연결은 사용자 제공 근거의 시연용 매핑이며 운영 DB의 기존 매핑이 검증된 것은 아니다.

### 증강현실 활용 목적

바코드는 상품을 식별하고 AR 평면 추적은 정보판을 배치할 현실 위치를 결정한다. 사용자가 상품 옆 책상을 터치하면 그 공간에 정보판이 고정돼 카메라 이동 중에도 현실 대상과 정보의 위치 관계를 확인할 수 있다.

단순 조회 효율만 보면 화면 카드가 더 간단하다. 본 프로젝트는 상품 식별과 현실 공간 배치의 역할을 나누고, 강의에서 학습한 마커리스 AR·사용자 상호작용을 구현·검증하는 데 목적을 둔다. 정보판이 상품의 이동을 자동으로 따라가는 것은 아니다.

## 2. 콘텐츠 목표

- 대상 사용자: 제품 옆에서 가격·영양정보를 확인하는 사용자.
- 사용 환경: ARCore 지원 Android 기기, 충분한 조명과 특징이 있는 수평 표면.
- 사용자 목표: 바코드로 정확한 시연 상품을 찾고, 상품 옆 현실 위치에 관련 정보를 배치·확인·재배치한다.
- 기술 목표: 같은 AR 카메라로 바코드를 판독하고 평면 Raycast·공간 고정·정보 표시를 결합한다.

## 3. 핵심 구현 내용

### 구현한 코드

- `ARReadiness`: 카메라 권한, AR 지원·설치 상태, 세션 준비와 복구 안내.
- `ARBarcodeScanner`·`BarcodeDecoder`: AR CPU 이미지 변환, 제한된 빈도의 비동기 EAN-13 판독, 메모리 해제와 스캔 세대 분리.
- `ProductCatalog`·`ProductWorkflow`: 정확한 바코드 연결, 누락값·출처 보존, 스캔·상품 선택·배치 상태 제어.
- `ProductPlacement`: 수평 평면 터치, 앵커 기반 정보판 하나의 배치·재배치·삭제, UI 터치 차단, 추적 중단 시 표시 숨김.
- `WorldProductPanel`·`ProductScreenView`: 한국어 상품·가격·영양정보와 다음 동작 안내.
- `ProjectBuilder`: Inspector 참조가 연결된 씬·프리팹 생성과 Android 빌드 설정.

코드·에디터 시험·APK 빌드·기기 실행·실물 판독은 서로 다른 검증이다. 최종 통과 판정은 검증 기록의 실제 결과만 사용한다.

### 한계와 향후 발전

- 현재 데이터는 한 상품의 시연 스냅샷이다. 운영 전체의 상품 등록 상태·현재 가격을 조회하지 않는다.
- 바코드의 3차원 위치나 상품 전체 Pose를 추정하지 않는다. 상품 이동 시 재배치가 필요하다.
- 실물 판독 10회, 공간 고정·추적 소실·5분 통합 시험은 실제 증거로 보완해야 한다.
- 사용자 지정 상품 등록, 비교·추천·구매·OCR·AI 분류·실시간 수집은 범위에서 제외했다.

## 4. AI 활용 표시

기획 비교, 강의자료 탐색, 코드 초안·씬 생성 도구·자동 시험·문서 작성에 Codex를 사용했다. AI가 작성한 결과는 Unity 컴파일·자동 시험·APK·기기 로그와 실물 시험을 구분해 검증한다. 제품 인식용 사진이나 바코드를 AI로 재작성하지 않았다.

## 5. 데모 영상 구성안

강의 제출 안내의 **1~2분, 음성 설명 제외** 조건을 따른다. 완성되지 않은 동작을 편집으로 성공한 것처럼 만들지 않는다.

1. 앱 실행과 바코드 스캔 화면.
2. 실물 더단백 바코드 판독과 정확한 상품명 확인.
3. 상품 옆 현실 표면 터치, 정보판 배치.
4. 휴대폰 이동에 따른 공간 고정 확인과 관측 날짜·영양 기준량 표시.
5. 재배치·삭제·다시 스캔.
