# 단발성 바코드 판독의 확정 방지

**후속 결과:** 실물 재시험에서 3회 반복 오독도 확인됐다. 최신 해상도 분석·수정·기기 결과는 [BARCODE-RESOLUTION.md](BARCODE-RESOLUTION.md)를 따른다. 이 문서는 첫 번째 수정의 당시 기록이다.

확인일: 2026-10-23 KST. 사용자 증상: 더단백을 비췄지만 “시연 데이터에 없는 상품”이 표시됨.

## 확인한 사실

- 등록된 시연 바코드는 `8801104671507`이며 JSON·정확 ID 연결은 변경하지 않았다.
- 기존 앱 기기 로그에는 19:01:21에 `5505256701701`, 19:01:28에 `7201143677507`이 `UnknownBarcode`로 처리된 기록이 있다.
- 이전 코드는 체크섬을 통과한 한 프레임의 판독만으로 상품 선택 또는 미등록을 확정했다. 같은 제품을 계속 비춘 상황이라면 위의 서로 다른 값은 오인식 가능성이 높다. 실제 영상·숫자를 대조한 실물 재현은 아직 없다.
- 입력 R8과 ZXing Gray8의 의미는 일치한다. ZXing [공식 소스](https://github.com/micjahn/ZXing.Net/blob/master/Source/lib/RGBLuminanceSource.cs)의 1 byte/pixel 정의를 대조했다. 이것이 실물 판독 정확도를 증명하지는 않는다.

## 수정

1. 서로 다른 카메라 프레임의 같은 EAN-13 번호가 **3회 연속** 확인된 경우만 상품 조회로 넘긴다. 0.35초 주기에서 최소 약 0.7초 동안의 일치를 요구한다.
2. 다른 번호·판독 실패·체크섬 실패·1.5초 초과 간격·다시 스캔에는 확인 횟수를 초기화한다. 이전 스캔 작업의 결과는 기존 세대 가드로 배제한다.
3. 스캔 중 확인 횟수를 표시한다. 미등록 화면에는 읽은 번호를 표시해 포장의 숫자와 대조할 수 있게 한다.
4. 모르는 번호를 시연 상품으로 대체하거나, 관찰된 다른 번호를 제품 매핑에 추가하지 않는다.

## 검증과 한계

- Unity EditMode **23/23 PASS**, 실패·건너뜀 0, 종료 코드 0. 근거: `artifacts/barcode-fix-tests.xml`, `barcode-fix-tests.log`.
- 추가 시험: 동일 번호 3회, 불일치/실패/간격 초과/재시작의 초기화, 실제 관찰된 미등록 번호에 대한 임의 상품 대체 방지.
- 기존 씬의 불필요한 생성 차이는 제거했다. Inspector 참조와 원본 제품 사진은 유지했다.
- 카메라 한 프레임의 오독이 즉시 미등록 안내로 이어지는 경로를 막았다. 반복적으로 같은 잘못된 값을 읽을 수 있으므로 **오인식 제거 또는 실물 정확도 개선을 확정하지 않는다**. 실제 제품에서 재시험해야 한다.
- 같은 기존 로그에 SessionTracking 진입과 잦은 SessionInitializing 전환, URP frustum 오류가 있었다. 안정된 공간 추적과 실제 정보판 배치 검증은 별도 미완료다. 이번 수정으로 해결됐다고 주장하지 않는다.
