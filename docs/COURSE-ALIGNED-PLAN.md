## 2. 권고 방향

**바코드로 상품을 식별하고, 사전 등록한 포장 이미지의 3D 자세에 World Space 정보판을 표시한다.**

- 별도 마커를 상품에 부착하는 대신 실물 포장 자체의 앞면이나 평평한 인쇄 영역을 참조 이미지로 사용한다.
- Reference Image Library의 사전 등록은 Chap4의 실습 과정과 일치한다. 이번 제출에서 이를 회피할 이유는 없다.
- 현재 카드에서 성공한 위치·방향 추적, 소실 시 숨김, 재획득 처리와 기존 상품정보 UI·데이터를 재사용한다.
- 우선 **상품 1종의 완결된 흐름**을 확보한다. 2번째 상품은 기본 동작·영상 확보 후 여유가 있을 때 추가한다.
- OpenCV/PnP와 자동 동적 이미지 등록은 [기술 조사 보고서](BARCODE-MARKER-RESEARCH.md)의 후속 연구 항목으로 둔다.
- 현재 AR Foundation 경로를 유지한다. Vuforia로 전환하거나 MultiTarget·영상 재생을 추가하는 것은 제출 전 필수 작업으로 잡지 않는다. 보고서에도 실제 사용한 Chap4 방법을 중심으로 설명한다.

## 3. 과거 이미지 실패와 vFlat의 역할

[과거 기록](M0-M3-validation.md)에 따르면 더단백 후보들의 arcoreimg 점수는 0~45점이었고, 한 후보는 특징점 부족으로 평가 자체가 실패했다. 당시 상품 이미지 추적 실기기 시험은 미실시였다. 따라서 모든 상품 이미지 추적이 불가능하다고 판정한 경험과 구분해야 한다.

짧은 변 228px인 후보도 있었지만 2545×836px 후보도 0점이었다. 해상도 증가나 여백 제거만으로 해결된다고 볼 수 없다. 반사·주름은 관찰했지만 각 요소의 영향을 분리 검증한 것은 아니다.

[vFlat 공식 설명](https://vflat.com/)은 경계 검출·잘라내기·원근 및 곡면 보정을 제공한다고 한다. 재촬영 후보를 만드는 도구로 시도할 가치는 있다. 다만 보정된 사진이 실물의 구김·반사를 제거하는 것은 아니며, 인식 성공을 보장하지 않는다.

권고하는 비교 절차:

1. 실제 시연할 포장과 동일한 디자인·규격의 영역을 평평하게 유지한다. 반사와 그림자를 줄이고 정면에 가깝게 촬영한다.
2. 일반 카메라 원본과 vFlat JPG를 둘 다 보관한다. OCR 결과나 재구성 문서 대신 이미지로 내보낸다. 강한 문서용 대비·흑백 변환·내용 제거 보정은 최소화한다.
3. 두 후보의 동일 영역을 arcoreimg로 비교한다. 짧은 변 최소 300px 이상과 충분한 실제 세부 정보를 확보하며 단순 확대를 개선으로 보지 않는다.
4. 선택한 이미지의 경계와 정확히 같은 실물 영역을 측정해 Physical Size를 설정한다. 강의 예제의 X:1을 복사하거나 이전 약 150mm 측정값을 다른 크롭 영역에 그대로 적용하지 않는다.
5. 먼저 큐브로 실제 포장을 인식·이동·회전·소실·재획득 시험한다. 점수 75 이상도 실물 통과를 대신하지 않는다.

사진 후보 검토는 짧게 제한한다. 같은 반사 포장 보정을 반복해도 낮은 품질이면 집에 있는 무늬가 풍부하고 평평한 종이 상자 제품으로 바꾸는 것이 낫다. 포장 이미지를 생성형 AI로 다시 그리는 방식은 참조와 실물의 대응을 깨뜨리므로 사용하지 않는다. 스캔 보정 도구를 사용했다면 원본·가공 내역을 보관하고 보고서의 도구 활용 내역에 적는다.

## 4. 바코드와 앞면 추적을 연결할 때 바꿀 규칙

상품 뒤쪽 바코드를 읽은 뒤 앞면으로 돌리면 바코드가 사라지는 것이 정상이다. 기존 v3의 0.65초 바코드 소실 시 숨김 규칙을 그대로 적용하면 앞면 이미지가 추적돼도 정보판이 사라진다.

새 흐름의 권고안:

1. EAN 판독으로 상품 ID를 선택하고 해당 참조 이미지 이름과 연결한다.
2. 앞면으로 돌리는 동안 선택 상품을 유지한다.
3. 선택 상품과 일치하는 이미지가 FULL_TRACKING일 때 그 자세에 정보판을 표시한다.
4. 이미지 추적 소실·제한·앱 pause에서는 정보판을 숨긴다. 재획득 시 같은 상품정보를 표시한다.
5. 다른 바코드 또는 다른 상품 이미지가 보이면 기존 정보가 잘못 겹치지 않게 숨긴다. 상품 전환은 명시적인 재스캔으로 처리한다.

World Space 정보판의 축·크기·표면 오프셋도 실물에서 확인한다. 영양/가격 탭 전환은 기본 추적·정보 표시 후 추가할 작은 인터랙션으로 둔다. 이를 위해 새 카메라 세션이나 새 AR SDK를 도입하지 않는다.

보고서에는 AR이 정보를 해당 실물의 위치·방향에 결합한다는 이유를 실제 시연 장면과 연결한다. 통계·사례는 원문 출처와 시점을 확인해 넣고, 현재 구현과 앞으로의 PnP·동적 등록 구상을 분리한다. 카드 검증 성공은 기반 기술 증거로 쓰되 상품 통합 성공으로 대신하지 않는다.

위 계획은 원문과 현재 성과를 바탕으로 한 권고이며, 특정 점수를 보장하는 루브릭 해석은 아니다. 후속 작업에서 [이미지 정보판·영양/가격 탭·재스캔](PRODUCT-IMAGE-TRACKING.md)을 구현하고 EditMode 76/76을 통과했다. 사용자 요청에 따라 앱 빌드·APK 생성·설치는 하지 않았다. 새 상품 사진 평가, Physical Size 확정과 상품 정보판의 실물 검증은 아직 수행하지 않았다.
